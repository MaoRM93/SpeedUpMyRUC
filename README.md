<h1 align="center">SpeedUpMyRUC</h1>

<p align="center">RUC 数智化门户加速与界面优化扩展</p>

<p align="center">快一点，干净一点，再好看一点。</p>

---

## 它解决什么问题

门户首页首次加载实测约 **42.5 MB / 347 个请求 / 63 秒**。拖慢速度的是装饰性素材和 HTTP/1.1 的连接拥堵：

| 现象 | 数据 |
| --- | --- |
| 首页顶栏动画 `banner_ruc.gif` | 单文件 **15.9 MB**，被完整下载两次，占总流量 73% |
| 子页面背景装饰图 `bg_img3-*.png` | 3 张合计 **3.31 MB**，占该子页面流量 42% |
| 进入子页面时重复下载 | 123 个资源里有 **116 个**与首页完全相同 |
| 连接模型 | HTTP/1.1，同一域名仅 6 条连接，347 个请求中 343 个打同一域名，排队累计 300 秒 |

扩展在网络层直接拦截这些对信息获取毫无帮助的素材，再把页面上无意义的装饰块和冗余文案隐藏掉，最后重做一套更清爽的视觉。

## 功能一览

菜单共五个分组、二十项，全部可以独立勾选，修改即时生效。

### 1. 快：网络层拦截

基于 `declarativeNetRequest`，在请求发出前就拦掉：

- 顶栏横幅动画（含静态帧）—— 约 15.9 MB
- 页面背景装饰图 —— 约 3.3 MB
- 页脚背景图
- 登录页失效验证码

配合域名预连接与图标预热，首页与子页面都能明显少下载、少等待。

### 2. 干净：页面精简

- 隐藏顶部装饰区、右侧悬浮栏与 AI 入口、机器人图标残留入口、右侧第 10 块推荐、移动端横幅静态帧
- 精简首页标语灰字、子页面标题灰字、「试运行」标签、首屏灰色副标题
- 标题下留白压缩：首页固定 40px，子页面取消 140px 的 `margin-bottom`
- 首页按使用频率重排：我的收藏 / 为您推荐优先，通知公告与日程紧随其后

首页五大板块——通知公告 + 日程中心、我的收藏 / 为您推荐、AI 智能服务、快捷导航、AI 简报 / 我的订阅——均可整块显示或隐藏。

### 3. 好看：界面重塑

- **搜索栏**：单行胶囊，白底细描边，聚焦人大红；AI 入口收为放大镜左侧的小图标；话筒图标统一为灰色
- **页签**：收藏 / AI 服务大页签改为 10px 圆角胶囊（44px 高、17px 字号），选中浅红底 + 人大红文字，切换平滑过渡
- **左侧导航**：圆角菜单项、浅红选中胶囊、去金色下划线；胶囊撑满侧栏宽度；桌面端 `fixed` 常驻，只滚动右侧内容
- **子页面**：办事大厅 / 管理平台 / 资讯中心等统一使用固定展开侧栏，不再出现 70px 迷你栏与抽屉
- **页脚**：中性灰底、次级文字色，版权行避开固定侧栏
- **图标**：通知公告 / 日程中心 / AI 简报改为与标题同色的透明底实心图标；浅色模式换红色矢量校徽
- **细节**：应用磁贴与「添加」去粗体；未选中的黄色模块转灰；头像与姓名去掉深色药丸底；「AI 中心 / AI 智能服务」补空格

### 4. 好读：三种配色与深色模式

菜单顶部先选配色，再选深浅色；主题在页面渲染前写入，不会白闪。

| 配色 | 侧栏 | 页脚 | 整页底色 | 深色 |
| --- | --- | --- | --- | --- |
| 简洁（默认） | 白色 | 中性灰 | 浅灰 `#f3f4f6` | 支持 |
| 色调 | 浅绯红 `#f5e3e1` | 米色 `#f0e7dc` | 暖米白 `#fcf7f0` | 支持 |
| 原始 | 人大红 `#861a12` | 中性灰 | 暖米白 `#fcf7f0` | 不支持（强制浅色） |

- 深色模式可「跟随系统 / 浅色 / 深色」，覆盖首页与管理平台等子页面
- 暗底上把人大红替换为高对比暖珊瑚红，整页底色转中性深灰
- 色调配色下侧栏与内容区只靠颜色区分，不画竖分割线
- 卡片始终保持白色 / 深色表面，避免整页糊成一片

### 5. 省心：自动保持最新

- 安装、启动时立即检查，之后每 15 分钟自动检查一次，没有关闭检查的开关
- 发现新版本后，门户右上角弹出更新日志卡片：完整 Release 说明、「前往下载」、「跳过此版本」、重新加载提示
- 跳过只隐藏这一版，后台继续检查，更高版本出现会再次提醒
- 支持开发者在紧急情况下远程停用：仓库发布 `114.514` Release 后，扩展自动停用并在页面顶部显示停用原因；该 Release 被删除后自动恢复

## 安装

扩展没有上架任何商店，需要以「已解压的扩展程序」方式加载。压缩包内附 **教程.html**。

| 浏览器 | 入口 | 按钮 |
| --- | --- | --- |
| Google Chrome | `chrome://extensions` | 加载已解压的扩展程序 |
| Microsoft Edge | `edge://extensions` | 加载解压缩的扩展 |
| 360 安全浏览器 | 菜单 → 工具 → 扩展程序 | 载入正在开发的扩展程序 |
| 360 极速浏览器 | 扩展图标 → 管理 | 加载已解压的扩展程序 |
| 华为浏览器 | 设置 → 扩展程序（`hwbrowser://extensions`） | 加载，或直接拖入文件夹 |
| 联想浏览器 | 设置 → 更多工具 → 扩展程序 | 加载，或直接拖拽文件夹 |
| Firefox | `about:debugging#/runtime/this-firefox` | 临时载入 `manifest.json` |
| Safari | Xcode 转制（`safari-web-extension-converter`） | 需 macOS |

简要流程：

1. 下载仓库代码或 Release 压缩包并解压
2. 确认文件夹**这一层**能直接看到 `manifest.json`
3. 打开浏览器扩展管理页，开启开发者模式
4. 点「加载已解压的扩展程序」，选中该文件夹
5. 打开 `my.ruc.edu.cn` 验证效果

> 安装后不要删除或移动这个文件夹，否则扩展会立即失效。

**Firefox 与 Safari 功能不完整**：Firefox 的 `declarativeNetRequest` 实现与 Chrome 有差异，可能出现「界面变干净但大图仍在下载」；未签名扩展重启失效。Safari 需 Xcode 转制并签名，网络拦截同样受限。日常使用建议 Chrome 或 Edge。

## 使用

点击工具栏图标打开设置菜单：

- **配色**：简洁 / 色调 / 原始，位于主题设置之前
- **主题**：跟随系统 / 浅色 / 深色；选择「原始」时仅保留浅色
- **分组开关**：组标题本身可点击，整组开关；部分选中时显示半选
- **单项开关**：网络拦截、页面元素、首页板块、文案、布局均可独立控制
- **检查更新**：底部显示当前版本与最新状态

网络拦截项对**之后的请求**生效，已缓存的大图刷新一次后消失；页面元素与布局项立即生效。

设置保存在 `chrome.storage.local`，带 `schema` 版本号；升级不会丢失勾选、配色与主题。

## 隐私

扩展不收集、不上传任何页面内容、账号或本地数据。所有操作都在本地完成。

外部请求只有三类：

1. `my.ruc.edu.cn` / `cas.ruc.edu.cn` 的图标预热与域名预连接
2. `api.github.com` 的公开 Release 列表（只读取版本信息）
3. 点击「前往下载」时打开本仓库的 Release 页面

```

items.js           拦截清单：分组、文案、选择器、规则集映射
rules/             4 个 DNR 规则集，可独立启停
  banner.json        顶栏横幅
  background.json    页面背景图
  footer.json        页脚背景
  captcha.json       登录页失效验证码
guard.js           远程停用守卫：最先执行，命中停用记录时停用页面效果并显示公告
theme.js           配色与深色模式（写入 html[data-ruc-palette] / html[data-ruc-theme]）

ui-cleanup.js      CSS 注入、文本兜底、灰字识别、模块重排
css/tokens.css     设计令牌（含深色与三套配色色板）
css/home.css       首页视觉改造与深色映射（仅 .mainPage 生效）
update-notice.js   右上角更新日志卡片（下载 / 跳过此版本）
popup.html/js      设置菜单：配色 + 主题 + 分组勾选 + 检查更新
content.js         域名预连接（preconnect / dns-prefetch）
background.js      图标预热、每 15 分钟检查 Release、远程停用与自动恢复

```

### 新增一个拦截项

所有条目集中在 `items.js`，菜单与页面脚本共用同一份定义：

```js
{
  key: "someBlock",            // 唯一标识，也是存储里的开关名
  label: "某个装饰块",          // 菜单显示文案
  note: "1.2 MB",              // 可选，右侧灰色注释
  css: ["#sui-app-page > div.css-1nl44e3"],  // 选择器，命中后 display:none
  texts: ["某段文案"],          // 可选，文本兜底（应对 MUI 拆分节点）
  entry: true                  // 可选，沿 a/button/li 向上找到整条入口再隐藏
}
```

网络层拦截需在 `rules/` 下新建规则文件、在 `manifest.json` 的 `rule_resources` 登记，并给条目加 `ruleset: "<规则集 id>"`。

## 已知限制

- 页面选择器基于门户实际的 MUI / Emotion DOM（形如 `css-1nl44e3` 的哈希类名）。**门户前端一旦改版，规则会失效**，需要重新取选择器。
- 拦截规则只覆盖已确认的装饰素材，不拦截任何内容资源（公告配图、正文图片等）。
- 网络层拦截依赖 `declarativeNetRequest`，Chromium 内核支持最完整。
